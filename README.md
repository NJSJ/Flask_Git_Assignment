# Flask & MongoDB Atlas DevOps Assignment

This project contains a Flask web application integrated with MongoDB Atlas and a static JSON API endpoint.

## Project Structure
- `app.py`: Flask application routes and logic.
- `config.py`: Environment configuration management.
- `data.json`: Source file for the `/api` endpoint.
- `templates/`: HTML interface (`form.html` and `success.html`).
